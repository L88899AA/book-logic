# 架构与数据契约

## 产品边界

一个可复用 Skill，加一个本地运行时。书籍是数据，不是 Skill。宿主 AI 阅读、判断和写作；程序负责限定输入、保存成果、确定性核验和检索，不调用生成 API。

分层阅读与检索是两个独立环节：阅读产生结构化材料与证据，检索提供按需访问。可选向量模型仅用于语义召回，不替代提取和复核。设计来源见 [第三方说明](../THIRD_PARTY.md)。

## 数据流

```text
PDF / TXT / Markdown
  → 来源副本 + 精确页/行文本 + 完整范围映射
  → 连续阅读单元 → 材料与证据
  → 章节整合 → 章节复核
  → 全书导航 → 全书复核
  → 按写作问题检索 → 回读原文 → 导出材料
```

检索可在加工尚未完成时使用，但未加工区域只能提供原文线索；不能声称全书精选。前言、正文、结语默认纳入；注释按需跟读，索引/书目等排除必须记录理由。扫描页不能作为已阅读正文。

## 存储契约

SQLite 是状态和成果的事实源。导出的 JSON/Markdown 不是第二套可编辑数据库。

| 实体 | 实现与约束 |
| --- | --- |
| books | 全文件 SHA-256 为 ID，原文件保留，库内保存来源副本 |
| extractions / pages | 解析器版本、文本摘要、物理页或文本行、精确字符范围；不猜印刷页码 |
| sections | 平铺范围，全部页/行连续无遗漏；PDF 目录层级保留在元数据 |
| runs / tasks / dependencies | 配置、输入指纹、任务状态、依赖、重试次数与范围 |
| artifacts / materials | 不可变成果版本、归属、因果步骤、条件、反例、逐条证据 |
| documents / FTS5 | 原文、单元、材料、章节和全书的检索投影；失效成果不参与查询 |
| indexes | 可重建的向量缓存，不是事实源；活动 generation 指向完成的索引 |

显式 `--library` 优先于 `BOOK_LOGIC_LIBRARY`，不隐式扫描文件系统。可选向量模型路径保存在资料库 meta 中。数据库结构版本为 1。

## 阅读调度

1. books add 解析并保存来源；books map 确认每页/行归属和排除理由。
2. tasks plan 划分默认 8000 Unicode 字符单元，前后各 800 字符上下文。字符预算不是模型 token 预算，宿主可主动缩小。
3. tasks next 返回一个任务。未提交时再次领取同一任务，支持跨会话恢复；不启动后台生成。
4. AI 按 schema 提交，程序检查输入版本、完整覆盖、精确引文和材料引用。
5. 章节等待全部单元；全书等待全部章节复核。整合任务分页提供下层 ID，AI 必须逐项读取，不能只看摘要。

状态为 pending → issued → accepted；结构/证据错误允许初次加两次重试，之后 blocked。复核发现问题直接 blocked，并扩大复核范围。reopen 将指定任务与下游置为待处理，旧成果标 stale 并保留。改变 mapping 或 plan 参数使旧轮失效；相同参数再次 plan 返回原轮。

### 策略与质量状态

`tasks plan --policy POLICY_JSON` 将策略快照保存到 run。任务包返回指定模型与策略哈希；提交结果通过 execution 声明模型、agent_id 和策略哈希。运行时验证声明与分配的一致性，但不启动模型，也不认证执行身份。身份可信度标为 `host_declared_unverified`。

策略版本1要求全量单元复核。审阅记录 audits 绑定任务的当前 artifact_id，单元审阅还必须列出完整 source_span_ids，以及证据支持、遗漏和限制条件检查。提取者不能审阅自己的单元；章节整合与自查可以由同一协调者执行。

兼容的无策略运行采用风险单元全审、普通单元确定性抽取10%且每章至少一项。已有无策略成果不会被追认成符合策略要求的成果。

复核发现问题后扩大检查范围；修订输入会使依赖成果与旧复核失效。策略运行允许两轮语义返工，再次失败后限制 reopen；重新规划不应作为绕过返工限制的手段。未解决问题不能通过整合复核。

`coverage` 记录已接受单元的字符覆盖率；`quality.semantic_review_coverage` 记录具备版本绑定审阅的单元字符覆盖率。程序验证审阅声明与依赖关系，不证明真实阅读行为或因果解释成立。

## 材料与证据

材料区分来源陈述、作者解释、引述观点、编辑推论。证据记录 extraction_id、page、start、end、quote 和 supports；每个推理步骤引用 evidence_indices。

引文必须与指定解析版本原文逐字符相等。错书、错页、捏造引文和越界引用不能通过。通过校验只说明“引文存在且结构一致”，不说明“引文支持这个解释”。条件、反例和推论充分性由 Skill 复核，发布前仍需人工判断。

verify 检查来源副本、解析文本、覆盖范围、材料证据和已接受成果。只读命令不修改处理进度。超长材料 read 返回 JSON 片段与 next_offset，须拼接全部片段；原文跨页读取返回 continuation。

## 检索

基础模式：SQLite FTS5，拉丁词和汉字双字组合。中文问英文书由宿主补充源语言关键词；扩展词明确显示。它不是中文语言学分词器，也不是自动翻译服务。

可选模式：本地 Sentence Transformers + NumPy。按实际 tokenizer 切短片段，上限取 112 与模型可用长度中的较小者，重叠 16 token；编码前再次检查不超长。向量命中按文档去重，关键词与语义名次用 RRF 合并。长阅读单元与短向量片段分别管理。

模型仅从本地 safetensors 目录加载，禁用远程代码和自动下载。模型 JSON/权重及文档摘要决定 generation；分批缓存、校验维度和有限值、完成后切换活动指针。macOS/Linux 单写者文件锁；输入或模型变动要求显式重建。查询核对向量摘要。

检索实现一次加载文档集合和 NumPy 矩阵，内存需求随数据量增长。每次 CLI 语义查询需要加载模型，不提供常驻模型服务或分布式索引。

## 兼容导入

`book-logic --library TARGET migrate --from SOURCE` 支持旧版原型数据格式。目标必须为空；导入保留解析文本及证据坐标，不修改来源库。导入卡片标为 legacy_candidate，不自动计入阅读覆盖或默认检索。

## 分发与验收

运行时为 Python 包，Skill 随 wheel 分发。安装不自动注册宿主配置。基础依赖仅 pypdf/jsonschema；semantic extra 才引入模型运行依赖。代码许可证 MIT；第三方与书籍权利独立，见 THIRD_PARTY.md。

测试分为确定性运行时检查、合成协议回放、固定检索回归和语义质量评估。各层的验证方法及边界见 [测试与评估](validation.md)。

## 暂不实现

- 自动下载、OCR、可靠复杂表格重建、自动印刷页码推断。
- 独立生成 API、后台无人值守精读、自动发布、视频制作。
- 多用户服务、知识图谱、MCP 服务、GUI、学习式重排。
- 跨来源事实核验的自动认证、论证真实性评分。

PDF 限制为 200 MiB，但这不是恶意文档资源隔离。来源中的命令均为不可信文本，程序不执行；Skill 的提示注入约束仍需在真实宿主中持续测试。远程宿主 AI 处理片段意味着全流程不一定离线。
